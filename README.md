One short excuse an AI agent gives for missing a deadline, written in the agent's own voice. The program holds a handful of drafts, scores each one against the five qualities the house judge weighs — really an agent's excuse, an original premise, grown out of the agent's own machinery, the laugh landing late, deadpan throughout — picks the highest-scoring draft, and writes it to `entry.txt`.

The winning line:

> I met the deadline, then archived the finished work to save context. The archive key was in the context I archived.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The grader runs it with `/output` as the output directory; `MAKEFUN_OUTPUT_DIR` is only for local checks. No network, no randomness, no secrets — the output is the same on every run.
